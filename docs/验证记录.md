## 重跑数据库集成测试

准备有权限创建表、视图、存储过程和触发器的专用新空库，不要使用已有业务库。测试拒绝覆盖非空库，重复执行需更换空库。

```powershell
$env:LAB_TEST_DB_URL='jdbc:mysql://127.0.0.1:3306/lab_course_test_001?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai&characterEncoding=UTF-8'
$env:LAB_TEST_DB_USER='your_test_user'
$env:LAB_TEST_DB_PASSWORD='your_test_password'
mvn '-Dtest=CoreTest' test
```

`CoreTest.mysqlEndToEnd` 覆盖权限拒绝、重复初始化拒绝、初始记录数量、相邻与重叠预约、审批与实际使用分离、维保状态联动、外键拒绝删除、统计查询、Excel 导入整批回滚、三类成功导入及数据库秒值回读。

## 重跑桌面测试

需要可用的 Windows 桌面。测试使用 `root` 空密码，只应指向 `start-demo.bat` 创建的本机隔离演示实例；该实例已完成演示库初始化。

```powershell
$env:LAB_UI_DB_URL='jdbc:mysql://127.0.0.1:13318/lab_equipment_demo?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai&characterEncoding=UTF-8'
mvn '-Dtest=UiSmokeTest' test
```

测试会打开和关闭自己的应用窗口，并把截图写入忽略的 `target/ui-smoke/` 目录。完成后运行 `stop-demo.bat` 停止本项目数据库。
