# MySQL 数据库课程设计说明

本项目是我的 MySQL 数据库课程设计作品，选题为“高校实验室设备共享预约与维保管理系统”，以 Java GUI 与 MySQL 管理信息系统的课程任务为依据。

## 选题与实践目标

实验室设备管理包含设备资料、预约计划、审批、实际使用、维保和操作记录，适合将数据库知识放到同一条业务链中练习。项目从这些记录之间的关系出发，实践主外键、唯一约束、规范化、视图、存储过程、触发器、事务及聚合查询，同时通过桌面界面完成数据管理和展示。

Excel 导入导出是课程明确要求的功能，因此实现了文件模板、表头与业务校验、错误行号提示、整批回滚和列表导出。

## 课程要求对应

| 任务要求 | 实现位置 |
| --- | --- |
| 至少五张表，各表至少五条记录 | `src/main/resources/schema.sql`、`seed.sql`；八张表，初始化记录至少五条 |
| 外键、视图、存储过程等数据库对象 | `schema.sql`；四个视图、三个存储过程、两个触发器 |
| Java GUI 增删改查和统计分析 | `App.java`、`LabService.java`、`Db.java` |
| 折线图和趋势图等可视化 | `App.java` 中的图表展示，统计口径由 `LabService.stats` 定义 |
| Excel 导入与导出 | `ExcelFiles.java`、`templates/`、`examples/` |
| 可运行 JAR 与源码工程 | `pom.xml`，构建生成 `target/lab-equipment-demo.jar` |

课程要求的“真实、准确”与记录数量是不同条件。当前公开的种子记录是教学模拟数据，正式验收仍需补充真实资料、采集时间、单位和来源，必要时对人员信息匿名化。

## 课程报告结构

课程任务要求报告控制在 15～35 个 A4 页面，并完整包含以下六章。报告围绕本项目组织为：

1. **设计构思规划**：选题背景、目标、角色、业务规则和数据来源。
2. **开发说明**：运行环境、依赖、代码组织、安装初始化和异常处理。
3. **数据库设计和数据字典说明**：实体关系、字段、主外键、索引、视图、存储过程和触发器。
4. **技术路线设计分析**：界面与 JDBC 调用、组件复用、审批与实际使用、权限及 Excel 事务。
5. **功能测试和使用说明**：测试环境、用例、执行结果、界面操作和局限。
6. **成果与展望**：已经实现的成果、当前不足与后续改进方向。

课程报告及其封面、打印材料由本地提交材料管理，公开仓库保留实现说明、演示截图和数据库文档。

## 成果提交形式

课程任务要求提交设计文档、可运行 JAR 与数据库文件、IDEA 项目源码压缩包，并打印课程报告。仓库提供可通过 IDEA 导入的 Maven 源码工程和 SQL 资源，可自行构建 JAR；本地交付中还制作了 Windows 便携 EXE，以方便课堂演示。

SQL 资源用于重建演示结构和初始数据，不等同于运行后业务数据的备份。
